# East Asia Trading — Premium Photography Redesign

This iteration updates all 17 root HTML pages with a consistent premium editorial design and photo-led presentation.

## Preview
Open `index.html` in a browser. Internet access is required for the premium Unsplash photographs and Google Fonts. Local original images remain in `images/`; product photos fall back to local images if remote image loading fails.
